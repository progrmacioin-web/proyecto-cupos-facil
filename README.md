
# Proyecto Cupo Fácil

Plataforma web para la gestión y reserva remota de citas médicas orientada a pacientes de zonas rurales, reduciendo colas presenciales e integrando validación OCR para el DNI y Hoja de Referencia.

## Estructura del Proyecto

```text
proyecto-cupos-facil/
│
├── proyecto-cupos-facil/   # Carpeta principal del proyecto
│   ├── css/
│   │   └── style.css       # Estilos globales y diseño Mobile-First
│   ├── js/
│   │   └── main.js        # Lógica de validación e interactividad
│   ├── img/                # Recursos visuales del proyecto
│   ├── index.html          # Pantalla de Inicio / Onboarding
│   ├── escaner.html        # Captura OCR de DNI y Referencia
│   └── seleccion_cupo.html # Selección de horarios y confirmación
└── README.md

```

## Tecnologías Utilizadas

* HTML5 (Estructura semántica)
* CSS3 (Variables, Flexbox y CSS Grid - Mobile First)
* JavaScript Vanilla (Validación de formularios y manipulación del DOM)
